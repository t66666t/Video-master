# Fluent Player 设计规范（笔记风 v2）

首页（媒体库）重设计的视觉基准。深色为主，浅色只预留、暂不启用。预览见 `docs/previews/home-redesign/index.html`（「规范一览」页签是本文档的实际渲染）。

风格参照 Notion / Obsidian 的深色界面：略偏暖的中性灰，靠明度区分层级；按钮平时只显示图标或文字，悬停时才出现浅底；少描边、少色块，强调色只用在真正需要注意的地方。

范围：布局、顶栏、按钮、控件、弹层、迷你播放器、悬浮按钮、多选栏。**封面不在范围内**：视频封面照旧，文件夹占位的三种画法和配色保持现状。

## 1. 原则

1. **层级靠明度，不靠描边。** 页面 → 弹层 → 菜单逐级变亮。描边只用作 1px 的细线，用来隔开同色块，不作为主要装饰。
2. **按钮安静。** 图标按钮和文字按钮平时没有底色，悬停时出现 `fill.hover`，选中时文字变亮。只有对话框里的主按钮有实心强调色。
3. **一个强调色。** 选中的开关、滑块、主按钮、「完成」、筛选生效时用 `accent`。顶栏标签的选中态用主文字色加下划线，不用强调色。
4. **一套弹层。** 菜单、底部弹层、对话框共用同一套表头、分组列表和按钮。窄屏从底部进入，宽屏居中。
5. **一种字体。** 全应用 MiSans，正文 400，标题 500 或 600。不再单独使用 Noto Sans SC，也不再用 300 字重。

### 强调与语义

默认强调色为蓝。预览里提供四个候选，审核时选定一个，另外三个删除。

| 候选 | `accent` | `accent.text`（深底上的文字） |
| --- | --- | --- |
| 蓝（默认） | `#4B8EF0` | `#7EB1FF` |
| 紫 | `#8B7CF6` | `#AB9FFA` |
| 琥珀 | `#D9A24A` | `#E8BB6F`（主按钮文字改为 `#1A1406`） |
| 绿 | `#4FA872` | `#74C293` |

`accent.soft` 为 `accent` 16% 透明度，用于选中底；`accent.ring` 为 55% 透明度，用于选中描边。

| Token | 值 | 用途 |
| --- | --- | --- |
| `danger` | `#E5625C` | 移入回收站、危险菜单项、危险主按钮 |
| `success` | `#4FA872` | 成功提示的图标 |
| `warning` | `#D19B3F` | 警告提示 |

品牌色只染图标：`brand.bilibili` `#FB7299`，`brand.ytdlp` `#FF5A52`，`brand.batch` `#A98BF2`。

## 3. 形状、阴影、字号、动效

### 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `r.xs` | 3 | 键帽、极小标记 |
| `r.sm` | 4 | 菜单项、卡片 dock 按钮、分组头封面、列表缩略图 |
| `r.md` | 6 | 图标按钮、对话框按钮、输入框、分段选中块、筛选胶囊 |
| `r.lg` | 8 | 菜单、分组容器、分段轨道、Toast |

| `r.full` | 999 | 开关、标签、悬浮工具条 |

卡片封面圆角仍随宽度变化：`(cardWidth * 0.045).clamp(4, 8)`。列表行圆角为 `min(原公式, 6)`。

### 阴影

深色界面里阴影只给浮在内容上方的东西：

| Token | 值 | 用途 |
| --- | --- | --- |

| `shadow.popover` | `0 0 0 1px #FFFFFF0F, 0 4px 10px #00000047, 0 14px 36px #00000066` | 菜单、对话框、宽屏弹层、搜索面板、Toast |
| `shadow.sheet` | `0 -1px 0 #FFFFFF0F, 0 -16px 48px #00000066` | 窄屏底部弹层 |

卡片、列表行、分组头、顶栏不使用阴影。遮罩为黑 50%。

### 字号

| 字号 / 字重 | 用途 |
| --- | --- |
| 16 / 600 | 弹层与对话框标题 |
| 15 / 500 | 宽屏顶栏标签、页面标题（文件夹内、搜索结果） |
| 14 / 500 | 紧凑顶栏标签、分组标题（600）、设置行文字（400） |
| 13 / 400 | 菜单项（指针设备）、对话框按钮（500）、筛选胶囊、标签 |

### 动效

| Token | 值 | 用途 |
| --- | --- | --- |
| `dur.fast` | 120ms | 悬停、开关、选中 |
| `dur` | 180ms | 展开箭头旋转、菜单弹出、顶栏滚动线 |
| `dur.sheet` | 240ms | 弹层进入 |

弹层进入：窄屏上移 16 并淡入；宽屏和菜单从 97% 缩放淡入。

## 4. 首页布局

### 顶栏

- 与页面同色 `bg.base`，没有独立色带。内容滚动后底部出现 1px `line.subtle`。
- 高度：宽度 < 600 时 **44**（原 50）；否则 **48**（原 56）。
- 最左是视图切换（列表 `view_list` / 卡片 `grid_view`）；进入文件夹或搜索后变为返回，多选时变为关闭。
- 三个入口是文字标签：未选中 `text.3`，悬停 `text.2`，选中 `text.1` 并在底部加 2px `text.1` 下划线。紧凑 14/500，宽屏 15/500。
- 进入文件夹时中间显示「标题 + 小号项目数」，搜索时显示「搜索结果 + 关键词」。
- 右侧图标按钮 32×32，图标 20，`text.2`。宽屏的 9 个按钮按用途分三组，组间用 16px 高的 `line` 竖线隔开：全屏 / 大文件目录 / 导入导出 ｜ 搜索 / 定时 / 回收站 ｜ 样式 / 设置 / 批量管理。紧凑顶栏为搜索、定时、回收站、更多，「更多」菜单里放导入导出、大文件目录、样式、设置、批量管理。

### 卡片

- **卡片底色沿用原来的 `#2C2C2C`，无边框。** 选中时整格改为 `accent.soft`。
- 封面固定 16:9，内侧 1px 白 5% 细线，防止深色封面和页面糊在一起。观看进度贴在封面底边，高 **3**，`accent`，轨道黑 45%。
- 标题最多两行，左边与封面对齐。标题下一行是「元数据 + dock」：文件夹前加 `folder` 小图标，音频前加 `music_note`。
- 操作 dock（更多、显示所在目录）尺寸公式不变（卡片宽的 19%）。改为无底色，图标 16，`text.3`，悬停 `fill.hover` + `text.1`。
- 多选：勾选圈在封面右上角，未选白色带投影，选中实心 `accent`；选中卡片整格 `accent.soft`，封面加 2px `accent` 外圈。

### 列表

- 行无底色，悬停 `fill.hover`；选中 `accent.soft` + 1.5px `accent.ring` 内描边。
- 缩略图圆角 `r.sm`。dock 在行内垂直居中，样式同卡片 dock。

### 分组头

- 左右内边距与网格外边距对齐，上下 **8**（原 10）。整行可点，悬停 `fill.subtle`。
- 封面叠放尺寸不变（40×28，错开 12），圆角 `r.sm`，每张加 1.5px `bg.base` 外圈。
- 标题 14/600，副标题 12/`text.3`（如「文件夹导入 · 4 项」）。收起时右侧显示「其余 n」。
- 展开箭头 18，`text.3`，旋转 180ms，不再替换字形。

### 筛选胶囊（继续学习）

- 高 **28**，圆角 `r.md`，无底色无描边：`[filter_list] 全部记录 [expand_more]`，13 号 `text.2`。悬停 `fill.hover`。
- 筛选生效（继续观看）时：`accent.soft` 底 + `accent.text` 文字。
- 点开是菜单：全部记录 / 继续观看（选中项右侧 `check`），分隔线，门槛设置…。

### 迷你播放器

- 改为**悬浮卡片**：距左右和底边 **8**，圆角 `r.xl`，`bg.overlay`，`shadow.float`。宽度 ≥ 900 时居中，最大宽度 760。
- 高度：手机与桌面 **96**（原 124），平板宽度（600 ≤ 宽 < 1200）**112**（原 146）。
- 两行，功能不变：
  - 第一行：方形缩略图（38 / 46，圆角 `r.md`）｜标题 14（平板 15）/500 + 当前字幕 12/`text.3` ｜播放列表按钮
  - 第二行：已播时间｜进度条（3px，已播 `text.1`，拖动点 10）｜总时长｜上一个、播放/暂停、下一个、静音
- 播放/暂停是 `text.1` 实心圆 + `bg.base` 图标，其余按钮为普通图标按钮（30 / 34）。

### 悬浮按钮

- 改为**一条竖向工具条**：宽 **44**（手机）/ **40**（宽屏），圆角全圆，`bg.overlay`，`shadow.float` + 1px `line` 描边，内边距 4，按钮间距 2。
- 按钮直径为工具条宽减 8（36 / 32），图标 20。悬停 `fill.hover`。
- 批量字幕、新建合集、导入用 `text.1`；B 站、YT-DLP、批量导入只把图标染成品牌色。批量导入的提醒点为 6px `danger`。
- 收起按钮在最下方，用 16px 宽的 `line` 分隔，图标 `text.3`。收起后只剩这一个按钮。
- 位置：右边距 12，底部在迷你播放器上方 12。

### 多选栏

- `bg.raised`，顶边 1px `line.subtle`，按钮居中排列。
- 按钮：图标 20 + 11 号文字，最小宽 88，圆角 `r.lg`，悬停 `fill.hover`。
- 移入回收站为 `danger`；导出、重命名为 `text.1`（图标 `text.2`）。不再使用 `#AEB8FF`。

### 其他

- 「有新添加内容」提示：吸顶小胶囊，`bg.overlay` + `shadow.popover`，左侧 6px `accent` 圆点，12 号字。
- 拖放导入遮罩：内缩 8，圆角 `r.xl`，1.5px `accent.ring` 虚线框，底色黑 86%，图标 40 `accent.text`。
- 空状态：图标 40 `text.4`，文字 13 `text.3`。

## 5. 弹层

三种容器共用内部结构：

```
表头：左侧标题 16/600（可带 12/text.3 说明），右侧「完成」文字按钮
内容：左右 20，底部 20
分组标签：12 / 500 / text.3，上 16 下 6
分组容器：fill.subtle 底，1px line.subtle 内描边，圆角 8
行：最小高 44，左右 12，行间 1px line.subtle（左侧缩进 12）
```

### 菜单（Popover）

用于卡片「更多」、继续学习筛选、紧凑顶栏「更多」。

- `bg.overlay`，圆角 `r.lg`，`shadow.popover`，内边距 4，最小宽 200。不用毛玻璃。
- 菜单项：触屏高 36 / 14 号；指针高 30 / 13 号。图标 18（指针 17），`text.2`，与文字间距 10。圆角 `r.sm`，悬停 `fill.hover`。
- 选中项右侧 `check`，`accent.text`。危险项文字和图标都用 `danger`。分组之间用 1px `line.subtle` 分隔。
- 优先在锚点下方 4px 左对齐弹出，放不下时翻到上方；靠右时右对齐。

### 底部弹层 / 面板（Sheet）

用于样式调整、媒体库设置、继续观看门槛、导入、播放列表。

- 宽度 < 900：从底部进入，`bg.raised`，顶部圆角 `r.xl`，顶部居中拖动条（32×4，`line.strong`），最大高度 80%，`shadow.sheet`。
- 宽度 ≥ 900：居中面板，最大宽度 520，四角 `r.xl`，`shadow.popover`，没有拖动条。
- 点遮罩或「完成」关闭，Esc 关闭。

### 对话框（Dialog）

用于重命名、新建合集、确认、大文件目录、定时关闭、文件夹占位。

- 与宽屏面板同一外观，宽 400。
- 底部按钮右对齐，间距 8：次按钮 ghost，主按钮 primary；危险确认的主按钮用 danger。

### 搜索

- 面板距顶部 12% 居中，最大宽 640，`bg.overlay`，圆角 `r.xl`，`shadow.popover`。手机上左右 8。
- 输入行高 52：搜索图标 20 `text.3` + 无边框输入框 16 号。
- 底部提示条：`Enter 搜索`、`Esc 关闭`，12 号 `text.3`，键帽 11 号 `fill.control` 底 `r.xs`。

### Toast

- 顶部居中，`bg.overlay`，圆角 `r.lg`，`shadow.popover`，13 号字。
- 左侧 18 号图标：成功 `check_circle`（`success`），普通 `info`（`text.2`）。2.4 秒后消失。
