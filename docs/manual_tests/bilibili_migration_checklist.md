# B 站迁移批次 · 用户手测清单

在真机（安卓手机 / 平板）和 Windows 笔记本上逐条手点，通过就勾上。
有问题请记下：设备、窗口大小或横竖屏、操作步骤、看到的结果。

---

## 0. 已确认的行为（用户已定）

- **电脑上停靠的 B 站边栏开着时按返回键（Esc / 系统返回）**：直接退出播放页，和字幕边栏开着时一样，保持现状。
  （手机横屏时 B 站面板盖在视频上，按返回会先收起面板，这一点不变。）
- **窗口拖窄、B 站详情临时收起后显示什么**：按字幕列表自己的记忆。字幕列表记忆是开着的，就显示字幕列表；记忆是关着的，就只留视频，不显示边栏。
  拉宽后，B 站详情按它自己的记忆恢复。两边的记忆互不影响：拖窗口不会改字幕列表的记忆，也不会改 B 站详情的记忆。

## 1. 手机实际转屏（安卓手机）

- [ ] 竖屏播放 → 转到横屏 → 再转回竖屏：画面、进度、字幕不跳，不重新加载。
- [ ] 横屏点「全屏」进入、再退出：控件位置正确，退出后回到进入前的样子。
- [ ] 手机横屏打开 B 站面板（盖在视频上）→ 点面板上的「退出全屏恢复」：面板收起，播放器恢复到之前的状态。
- [ ] 手机横屏时 B 站面板只能点按钮打开，不会自己弹出来。

## 2. 加载页

- [ ] 点开一个 B 站视频：先看到封面、标题和加载圈，之后进入播放页时没有闪烁或跳动。
- [ ] 断网或拿不到视频时：显示失败原因和「重试」，点重试能再加载。
- [ ] 加载中按返回：回到原页面，不会过一会儿又自己跳进播放页（请求已取消）。
- [ ] 冷启动（刚打开 App）和热启动（已用过一会儿）各点开一次：感受一下等待时间，记下是否明显变慢。
- [ ] 竖屏加载页切到「字幕」标签 → 进入播放页后仍是「字幕」标签；
      退出后再打开另一个 B 站视频，播放页仍是你在播放页里上次选的标签（加载页的选择不改记忆）。

## 3. 播放列表

- [ ] 清空播放列表：没有确认框，底部弹出「已清空播放列表」和「撤销」，5 秒内点撤销能恢复原列表和顺序。
- [ ] 5 秒后提示消失，不能再撤销。
- [ ] 清空时正在播的视频：继续播放，不停下也不从头开始。

## 4. 自动导入与临时卡片

- [ ] 设置里「自动导入」**开**：看完一个 B 站视频按返回，媒体库里留下正式卡片。
- [ ] 「自动导入」**关**：看完按返回，只是临时卡片（不进正式媒体库）；
      再次打开同一个视频，行为和之前一样（不重复、不报错）。

## 5. 迷你播放器

- [ ] 多 P 视频缩成迷你播放器后切换分 P：画面和标题都换成新的分 P，进度从新分 P 的记录开始；
      点开回到播放页，显示的是新分 P。

## 6. 第 10 批 · B 站字幕（横屏字幕边栏、竖屏字幕面板都要看）

- [ ] **用 BV1GJ411x7h7 测登录前后**（横屏字幕边栏、竖屏字幕面板各看一遍）：
  - [ ] 未登录打开：「B 站字幕」区显示灰色的字幕名（点一下会请你登录），下面一行「这个视频有字幕，登录后可加载」；
        不出现「这个视频没有字幕」，不一直转圈。
  - [ ] 如果 B 站没给出这一 P 的字幕名：只显示「这个视频有字幕，登录后可加载」这一行。
  - [ ] 点这一行登录，回到播放页：列出 CC 和 AI 字幕（AI 带「AI」标记），点一条就加载。
  - [ ] 登录过期时：显示「这个视频有字幕，登录已过期，重新登录后可加载」。
- [ ] 未登录时 B 站直接给出的字幕照常能选；这时 AI 字幕需要登录，下面一行「登录后可加载 AI 字幕」。
- [ ] 点一条字幕：加载并显示，可以和本地字幕一样设为主字幕或副字幕；再点同一条：关闭。
- [ ] 播放中切换分 P：字幕列表换成新分 P 的；手动关掉字幕后，分 P 数据到达时不会自己重新打开。
- [ ] 没有字幕的视频（登录与否都一样）：显示「这个视频没有字幕」，不转圈。
- [ ] 字幕列表拿不到时：显示「字幕列表暂时拿不到，点一下重试」（断网时是「网络不通，字幕列表暂时拿不到，点一下重试」），点一下会重试。
- [ ] 断网播放已下载的 B 站视频：只列已下载的字幕文件（没有时显示「这个视频没有已下载的字幕」），不报错。
- [ ] 加载页、临时卡片、追加列表、占位卡片都和以前一样。

## 7. 第 10 批 · 窄窗口顶栏（修复 A）

- [ ] 宽窗口（例如 1280×720）：顶栏按钮的种类、顺序、位置都和以前一样，没有「更多」。
- [ ] 窗口缩到 640×360 并打开字幕边栏：标题可见，单行，太长显示省略号，鼠标悬停显示完整标题；右侧出现「更多」（⋮）。
- [ ] 「更多」里先收进去的是合成、OCR、字幕编辑这些不常用的；播放、字幕、B 站按钮最后才收；
      每项都有图标和文字，点了就是原来的功能。
- [ ] 按钮被收进「更多」后，快捷键仍然有效：V 合成、O OCR、I B 站面板；左手模式也试一遍。
- [ ] 手机横屏用的是同一套规则；B 站面板的「退出全屏恢复」行为不变。

## 8. 第 11 批 · 宽屏网格

- [ ] B 站搜索结果（视频、用户）、UP 主页（投稿、专栏、合集，以及合集详情）、观看历史：
      窗口拉宽时列数跟着增加（列表区域约 940 宽时 2 列，约 1410 宽时 3 列，约 1880 宽时 4 列，最多 4 列），拉窄回到 1 列，和以前的列表一样。
- [ ] 手机竖屏和手机横屏都是 1 列。
- [ ] 拖动窗口改变列数时，列表停在原来看到的位置附近，不会跳回顶部。
- [ ] 宽窗口下一页结果填不满屏幕时，会自动加载下一页；底部「没有更多了」「点此重试」占满整行。
- [ ] 下载任务页保持单列（任务可拖动排序、分 P 缩进，不做网格）。

## 9. 第 11 批 · 拖窗口时 B 站边栏临时收起 / 恢复（Windows、平板）

- [ ] 横屏播放 B 站视频、B 站详情边栏开着，把窗口拖窄到「窗口宽 − 边栏宽 < 640」：B 站详情自动收起。
      之后显示什么按字幕列表的记忆，而不是总显示字幕列表：
  - [ ] 字幕列表记忆开着：换成字幕列表。
  - [ ] 字幕列表记忆关着：不显示边栏，视频占满宽度。
- [ ] 再拖宽：B 站详情按它自己的记忆回来（原来开着就回来）；字幕列表的记忆不受影响。
- [ ] 整个过程中，只有顶栏 B 站按钮和边栏收起键会改 B 站详情的记忆，只有字幕列表自己的开关会改字幕列表的记忆，拖窗口两边都不改：
      关掉播放页重新打开（宽窗口），B 站详情和字幕列表是否打开都和拖窗口之前一样。
- [ ] 边栏让位后打开字幕管理等临时面板，再关掉：窗口仍窄时按字幕列表的记忆显示（开着显示字幕列表，关着只留视频）；已拉宽时回到 B 站边栏。
- [ ] 窄窗口时手动点 B 站按钮打开边栏：边栏留着；再拖宽也不消失。
- [ ] 平板横屏（按同样的 640 规则）：转屏或分屏改变宽度时同样收起 / 恢复。
