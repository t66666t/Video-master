## 结论

- API：`LibraryService.canRelocateLocalMediaSource` / `relocateLocalMediaSource`。不调用 `addSingleVideo`，不新建卡片/批次。
- 横/竖屏既有缺失面改为 `MissingLocalSourcePanel`：本地失联显示「文件找不到」+「重新定位文件」；在线/B 站仍为「没有原媒体」且无本地关联按钮。
- 取消选文件无副作用；类型不符/路径不可读不改库；成功后保留 ID、目录、进度、固定/隐藏、托管字幕；`addedAt`/`lastPlayedAt`/批次不变。
- 派生 `playbackPath`/生成预览失效；更短时长截断 `lastPositionMs`。
- 当前项占用播放器时 `MediaPlaybackService.reloadAfterSourceRelocate` 且 `autoPlay: false`；迟到的 A 回调不停止 B。
- 队列走既有 `reloadPlaylist` / `refreshQueueEligibility`。
- 音乐播放页无 `_isSourceMissing`：**延期**，待该页具备与视频页一致的缺失态后再接线。
- `simple_video_player_screen` / 预览页仍是「媒体文件不存在…」，未发明第二套库内重定位。
