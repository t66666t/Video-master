# 验证记录目录

每完成一个阶段，由执行 AI 新建对应 Sxx.md，记录：
- 阶段编号、日期与实际工作区事实；
- 本阶段涉及的行为和文件；
- 精确执行命令、exit code、结果；
- 新增问题 / 基线已有问题 / NOT RUN 的区分；
- 必要截图位置或人工操作步骤；
- 下一阶段须知道的短结论。

测试没有运行就标 NOT RUN；阶段尚未验收不能标 done。截图应来自实际运行，不用生成图冒充。不要保存账号、cookie、用户私有媒体清单或超长完整日志。

必须区分三种证据，不得把静态阅读写成测试通过：
- 源码已确认：rg/片段阅读看到符号或调用链；
- 测试实际通过：本阶段真实执行且 exit code 0；
- 仍待运行验证：有测试文件或手工步骤，但本环境没跑。
