## 入库来源覆盖表

| 来源 | 批次边界 | 实际提交点 |
|---|---|---|
| B站在线多选/单集 | 一次 `importStreamingToLibrary` / `importParsedStreamingTaskToLibrary` | `_importStreamingToLibrary` → `addSingleVideo(..., activityBatchId, bilibili)` |
| B站已下载导出 | 一次 `importToLibrary`（多选同一调用一批；自动逐集则每调用一批） | `addSingleVideo(..., bilibili)` |
| YT-DLP 手动多选 | 一次 `importToLibrary` | 同上 `ytDlp` |
| YT-DLP 任务自动完成 | `_handleCompletedTaskAutomation` → `importToLibrary(task:)` 各任务一批 | 同上 |
| FluentPack 目录迁入 | 一次 `importPortablePackageDirectory` | `_importDirectoryTreeIntoLibrary(..., fluentPack)` |
| FluentPack 快照恢复 | 一次 `_importSnapshot` | `addSingleVideo` 新 ID + `completeImportBatch`；失败 `abortImportBatch` |
| 下载完成本身 | 不记批次 | 仅真正 `addSingleVideo` 时登记 |

`applyPortableMediaMetadata` 仍只恢复进度/字幕/封面等，忽略源设备活动。未改 FluentPack 格式版本。同链接 B 站仍 `reuseExistingItem: false`。
