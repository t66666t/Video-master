## 结论

- `LibraryWatchMeter` 用 fake clock：入列 min(30s, 20% 时长) / 未知 30s；只计 playing 且位置前进；dt 超出 (0, 6000] ms 丢弃；2x 不加倍。
- 暂停、缓冲、seek、缺源不计；A→B 后丢弃 A 的 sample；确认完成走 `onConfirmedComplete`，seek 近末尾不算完成。
- 已完成项新周期达门槛才 `uncomplete`；同周期 `noteHidden` 后不 unhide，用户新周期才可。
- `MediaPlaybackService`：用户 `play()` 开新周期，自动连播/恢复 `userInitiatedWatch: false`；横竖屏/画质等同媒体 `retainCycle`。
- pause / persist / 切集 flush；确认完成先 `isConfirmedPlaybackCompletion` 再写 completed，再归零位置。
- `applyWatchFlush` 走既有进度节流；uncomplete/unhide/completed 立即落盘。
- 接线测试：pause 与 `persistCurrentProgress` 把 `accumulatedWatchMs` 写入 LibraryService；源码含 complete/pause flush。
