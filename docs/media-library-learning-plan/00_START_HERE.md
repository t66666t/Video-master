# Cursor 执行入口：媒体库学习入口改进

这是一套可以直接交给 Cursor Agent 执行的完整提示词。它按阶段分文件，目的是控制阅读量和修改范围。请在项目根目录打开本文件；不要一次读完全部计划。

## 给使用者

将下面这段话发给 Cursor：

> 请按 docs/media-library-learning-plan/00_START_HERE.md 执行。先读 CONTRACT.md 和 PROGRESS.md，只完成首个未完成阶段。读取当前工作区为准，保护现有未提交修改，按阶段文档实施、验证并写回交接记录。本轮结束后停在阶段边界，不提前实现后面的阶段。不要通读整库或整套计划，不要仅给建议。

下一次新会话发同一段话即可。若希望连续执行，可以明确说“连续完成”，但每阶段仍须单独验收和更新交接，不能把所有阶段展开为一个大改动。

## 给执行 AI 的总指令

你是实现工程师。产品目标是让用户迅速找到新导入、未看完和已归档的媒体。根据本计划修改代码，不另行发明学习平台。

1. 首次读取本文件、[CONTRACT.md](CONTRACT.md)、[PROGRESS.md](PROGRESS.md)，然后只读当前阶段文件。
2. 当前真实源码、用户新增要求和仓库 AGENTS.md 优先于本计划中的历史定位；若事实已变化，更新交接，不覆盖新代码来迎合旧描述。
3. git status 中已有大量修改和未跟踪文件，核对期间也观察到其他字幕组件持续更新。这些是有效工作，不是待清理垃圾。每阶段重新核对拟修改文件的当前内容，避免覆盖并行工作。禁止 reset、clean、checkout 恢复、批量格式化、擅自提交或升级依赖。
4. 先 rg 定位符号，再读相关函数及直接调用者。home_screen.dart、collection_screen.dart、library_service.dart、media_playback_service.dart 都很大，禁止作为默认动作整文件阅读。每次建议读取 100—220 行；初始阅读通常 3—6 个文件，证据需要时逐步扩大。
5. 不读播放器解码、字幕渲染、OCR、原生平台、模型资产等无关内容。文档《项目介绍.md》可能落后，不作为必读。
6. 复用最新版布局与交互组件，禁止重新设计全部卡片、复制巨型页面，或为了新入口改写播放状态机。
7. 一个阶段只交付本阶段功能和必要测试。若后续阶段尚未提供依赖，可以保留明确内部接口，但不得暴露可点击的空功能或假数据。
8. 实施前简短说明本阶段目标和阅读文件；完成后报告行为变化、验证结果、剩余问题。普通实现选择自行决定，不反复请求确认；只有真实产品冲突或无法安全继续时才提出一个具体问题。
9. 写回 PROGRESS.md，详细验证结果放 validation/Sxx.md。完成验收才标 done。当前环境不能验证的项目写 NOT RUN，不能写通过。
10. 默认阶段结束即停，方便用户换新上下文继续。这是执行节奏，不是每阶段都要审批的要求。
