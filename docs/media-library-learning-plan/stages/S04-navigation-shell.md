# S04：在新版 UI 上接入三个入口与返回状态

依赖 S03。此阶段只完成小型导航骨架和状态；新内容视图在S05/S07接入。尚未可用的入口不暴露为能点击的空功能。

## 最小阅读

- home_screen.dart：build、顶栏、迷你播放器/浮动按钮布局、revealItemId/returnToSearchResults处理。
- collection_screen.dart：构造函数、_showInParentDirectory、_openParentDirectory、返回与搜索入口。
- media_library_layout_profile.dart、media_library_compact_app_bar.dart：尺寸与样式使用方式。
- settings_service.dart：相关设置注册和保存；main.dart 只在启动恢复必须挂接时定位 HomeScreen创建处。
- test/media_library_overlay_identity_test.dart、test/media_library_compact_app_bar_test.dart。

## 实施约束与理由

1. 根页增加“继续学习 / 最近添加 / 文件夹”的轻量切换区，搜索和播放卡不复制。目录页继续复用 CollectionScreen，不在每一层再建一套导航。
2. 新装默认最近添加；首次升级旧库默认文件夹。用户已经选过入口则优先恢复选择。旧库判断使用数据迁移/已有内容证据，不把“初始化尚未读完”当空库。
3. 三个入口各保留滚动/展开状态；文件夹入口保留最后真实目录。优先记录稳定项/批次ID作为可见锚点及必要偏移，布局变化或内容删除时安全回退，不能只用旧像素值跳进错误项目。跨启动只持久化有限导航状态，不保存整个路由树或全部目录滚动历史。
4. 进入播放器、批次详情、固定目录、搜索后返回，应回到原入口和位置。显式“定位到文件夹”则进入文件夹入口并高亮原项。
5. 尤其保留 HomeScreen(revealItemId..., returnToSearchResults...) 的用途：定位导航必须强制展示真实目录，不被最近使用的全局入口覆盖；返回搜索结果不能绕回错误的主页副本。
6. 初始化完成后再恢复目录；目录已删除/回收时回退到最近有效祖先或根目录，不连续推入多个重复路由。
7. 切换入口前退出旧选择模式并清空其选中ID，不将目录拖拽索引带进虚拟结果。浮动操作/迷你播放器的稳定 key、动画和底部避让沿用。
8. 根据最新版布局组件扩展小块切换UI。严禁复制 HomeScreen 建成两个新巨型页面；也不要求一次合并 home/collection 全部历史代码。

## 验证

用注入的轻量内容构建器验证导航状态，不用加载全部播放器：
- 入口切换、详情返回、搜索返回、定位真实目录。
- 重启恢复；初始化延迟和缺失目录回退。
- 手机窄屏/横屏切换，顶栏、导入进度和迷你播放卡不覆盖切换区。
- 现有回收投放区与选择态仍显示；切换入口不会误移动旧选择项。
- 用户旧样式设置和封面配置未被新默认值覆盖。

本阶段可先把导航状态与切换组件通过测试准备好，只挂载已经具备内容的入口。S05/S07显露剩余入口；S11不得留下未接入占位或临时开关。
