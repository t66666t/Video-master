# S07：继续学习、固定和不再显示

依赖 S06。已有记录规则在S06完成；本阶段实现投影和UI，不能在组件里另做一套资格判断。

## 按需阅读

交接中的活动投影API；S04导航入口；S05媒体项复用方式；home_screen.dart播放导航回调；mini_playback_card.dart仅必要接口；library_rename_dialog.dart/原定位回调仅确认原目录管理仍可达。

## 页面行为

1. 顶部“固定”区域，下方“最近在看”；未知旧播放时间另标“之前未看完”。无记录时说明“播放一段媒体后会出现在这里”，提供前往最近添加/文件夹，不自动列入全库。
2. 最近在看按直接父目录分组，每组展示最近有效播放的一项，可展开其余项；根目录散片分别展示。组名从当前目录读取，不猜课程，不把同名不同ID目录合并。
3. 列出标题、所属路径、已保存位置/总时长，提供清楚的继续播放。保持当前卡片/列表布局体系；窄卡信息不足时将次要信息放到详情/提示，不能挤坏用户列数。
4. 单击继续沿用原播放器导航与prepareLibraryPlayback；固定目录进入真实目录，固定视频沿用断点位置。播放状态恢复不自动播放。
5. 固定通过媒体/目录既有更多菜单加入；如旧卡无菜单，可加一个小操作入口，不重新设计整个手势系统。固定按加入顺序稳定排列，首版不提供固定区拖拽排序。
6. 同一媒体ID固定后不在下方重复占一条；同一目录被固定不自动隐藏其子项记录，因为固定目录本身只是导航快捷方式。
7. “不再显示”只作用继续记录；显示撤销提示。若该项已经固定，固定入口仍在，“取消固定”是独立且明确的动作。隐藏一个媒体不隐藏整个目录。
8. 项进入回收站或有回收祖先时从此页消失；恢复后允许回到原固定位置；永久删除彻底清理。失联本地项仍保留，失败状态不得冒充已看完。
9. 播放期间时间更新只刷新相关项；整组次序在低频事件或返回页面时更新，避免每秒重排导致点击目标移动。
10. 保留底部迷你播放卡：它控制当前一个媒体；本页展示多个学习入口，二者职责明确且不互相遮挡。

## 验收

- A/B两个目录交替观看，各能恢复自己的视频位置。
- 同目录多条折叠、根目录散片、同名不同目录、未知旧记录。
- 未播放媒体与目录可固定，重启保留；固定项改名/移动后展示正确。
- 隐藏、撤销、重新主动观看；当前播放不被隐藏操作意外停止。
- 完成归零不误显示为未开始；没有播放行为的仅打开不入列。
- 固定与继续记录去重、回收/恢复、缺失源可识别。
- 卡片/列表、触摸/键盘、底部播放器遮挡与返回位置。
